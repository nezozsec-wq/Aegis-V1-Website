Aegis V1 Commands

Complete command list for Aegis V1 Discord Moderation Bot.

🔨 Moderation

!ban @user reason
Ban a member from the server.

!unban ID reason
Remove a ban.

!mute @user time reason
Timeout a member.

!unmute @user
Remove a timeout.

⚠️ Warning System

!warn @user reason
Give a warning.

!warns @user
View warnings.

!unwarn @user
Remove a warning.

!clearwarns @user
Delete all warnings.

🛡️ Server Management

!clear amount
Delete messages.

!lock reason
Lock a channel.

!unlock reason
Unlock a channel.

!say message
Make Aegis send a message.

📜 Logs & Tools

!logs
View moderation history.

!rank @user @role
Give a role.

!derank @user @role
Remove a role.

!help
Show all commands.
